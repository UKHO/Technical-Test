# Technical Test

These are the technical tests that form part of the interview process for software engineering roles at the UKHO.

The test you will take will be decided upon during your interview.

## Prerequisites

Both challenges require the [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0), Git, and an IDE of your choice.

- [Ship Statistics App](src/Challenge1/README.md)
- [Front End](src/FrontEndChallenge/FrontEndChallenge.Web/README.md)
